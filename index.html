เชื่อมต่อ GitHub เพื่อเผยแพร่ผล

  1. เปิดหน้า สร้าง Fine-grained token (ล็อกอินด้วยบัญชีเจ้าของเว็บ)
  2. Repository access → Only select repositories → เลือก
  3. Permissions → Repository permissions → Contents → Read and write
  4. กด Generate token แล้วคัดลอกมาวางด้านล่าง

token จะถูกเก็บไว้ในเบราว์เซอร์เครื่องนี้เท่านั้น ใช้บนเครื่องของผู้ดูแลเท่านั้น อย่าใช้บนเครื่องสาธารณะ

ไม่สะดวกใช้ token? แล้วอัปโหลดแทนไฟล์เดิมในหน้า GitHub ของเว็บ
