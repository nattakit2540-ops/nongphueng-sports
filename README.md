# แข่งขันกีฬาอำเภอเกษตรวิสัย “หนองผึ้งเกมส์” 2026

เว็บไซต์จัดสาย ตารางแข่งขัน และบันทึกผลการแข่งขันกีฬาอำเภอเกษตรวิสัย “หนองผึ้งเกมส์” (ธีม ขาว · ชมพู · ฟ้า พร้อมแอนิเมชัน) — ไฟล์เดียว (`index.html`) ไม่ต้องติดตั้งอะไร

## ความสามารถ
- **หน้าแรก** — นับถอยหลังสู่วันแข่ง, ภาพรวม 6 ชนิดกีฬา, นัดถัดไป, ทำเนียบผู้ชนะเลิศ
- **ผังการแข่งขัน** — แพ้คัดออก 6 ทีม (สายบน / สายล่าง / ชิงชนะเลิศ) ผู้ดูแล **ลากทีมจากกล่องทีมมาวางในสายเอง** ได้ทุกประเภท (เริ่มต้นเป็นช่องว่าง ไม่จับคู่ให้อัตโนมัติ) และแตะคู่แข่งขันเพื่อบันทึกผล ผู้ชนะเข้ารอบอัตโนมัติ
- **สรุปเหรียญรางวัล** (หน้าแรก) — นับทอง/เงิน/ทองแดงตามศูนย์เครือข่ายอัตโนมัติจากผล (ทองแดง = แพ้รอบรองฯ 2 ทีมต่อประเภท)
- **ตารางแข่งขัน** — ดู **ตามทีม** (เลือกทีม เห็นทุกนัดทุกกีฬา รวมนัด “ถ้าชนะ” · เว็บจำทีมไว้ให้) · **ตามกีฬา** (เลือกกีฬา → ระดับ/เพศ เหมือนหน้าผัง) · ตามวัน (ปุ่มรูปกีฬา แสดงเฉพาะกีฬาที่แข่งในวันที่เลือก) · ตามสนาม · รายงานประจำวัน, แยกตามวัน กรองตามกีฬา รุ่น และค้นหา, สุ่มจัดตารางอัตโนมัติ, ส่งออก Excel (CSV), พิมพ์ / PDF
- **ตั้งค่า** (เฉพาะผู้ดูแล) — วัน เวลา เวลาพัก ชื่อสนาม จำนวนสนาม และนาทีต่อนัดของแต่ละกีฬา พร้อมตรวจทีมและสนามชนกัน

ประเภทการแข่งขัน (ทั้งระดับประถมและมัธยม) รวม 36 ประเภท 180 นัด
- ฟุตบอล · วอลเลย์บอล · ตะกร้อ — ชาย / หญิง
- ฟุตซอล — ชายเท่านั้น (ประถมชาย · มัธยมชาย)
- ปิงปอง — เดี่ยว ช/ญ · คู่ ช/ญ · ทีมผสม
- เปตอง — เดี่ยว ช/ญ · คู่ ช/ญ · ทีม ช/ญ

ทีมที่เข้าแข่ง: ศูนย์เครือข่ายที่ 8, 9, 10 (ชุดที่ 1 และ 2) — ผู้ดูแลจัดลงสายบน/สายล่างเองทุกประเภท

เวลาต่อนัด (เผื่อเวลาแล้ว): ฟุตบอล และ ฟุตซอล นัดละ 1 ชม. (รวมครึ่งแรก พักครึ่ง ~10 นาที และครึ่งหลัง) · วอลเลย์บอล 60 · ตะกร้อ 40 · ปิงปอง 15 · เปตอง 45

- ทีมเดียวกันไม่ถูกจัดให้แข่งชนเวลากันในกลุ่มเดียวกัน (ระดับประถม/มัธยม และเพศเดียวกัน) ข้ามทุกชนิดกีฬา เช่น ฟุตบอลชายประถม 09:00 แล้ววอลเลย์บอลชายประถมทีมเดียวกันต้องหลังจบ + พัก 15 นาที
- ค่าเริ่มต้น: **ปิงปองและเปตองใช้นักกีฬาคนละชุด** — ไม่นับว่าชนเวลากันเอง และไม่ชนกับกีฬาประเภททีม (ปิดได้ในหน้าตั้งค่า)
- กฎนี้ใช้กับ **ทุกชนิดกีฬา** (ฟุตบอล ฟุตซอล วอลเลย์บอล ตะกร้อ ปิงปอง เปตอง) และทุกประเภท — ทีมผสมนับรวมทั้งชายและหญิง
- **พักกลางวัน 12:00–13:00 น.** — ไม่เริ่มนัดใหม่ในช่วงนี้ เริ่มต่อ 13:00 น. · นัดที่เริ่มก่อนเที่ยงแข่งต่อได้แต่ต้องจบไม่เกิน 12:30 น. (ทุกกีฬา **ยกเว้นฟุตบอล** ที่ต้องจบก่อน 12:00 น.) · แก้ได้ในหน้าตั้งค่า
- ช่วงเวลาของแต่ละรอบเป็น **กรอบวางแผน** — ถ้าจัดในกรอบไม่พอ ระบบวางนัดนั้นในเวลาว่างที่ใกล้ที่สุดของวันเดียวกัน (ยังไม่ให้ทีม/สนามชนกัน) และแสดงกรอบสีส้มในหน้าจัดเวลา · ถ้าผู้ดูแลแก้เวลาเองนอกกรอบ ระบบถามยืนยันก่อน
- ทุกค่าแก้ได้ในหน้าตั้งค่า (กำหนดการ สถานที่ เวลาต่อนัด จำนวนสนาม เวลาพัก 0/15/30/60 นาที)
- ถ้ากำหนดเวลาเองแล้วชน ระบบปฏิเสธพร้อมบอกทีม รายการ และช่วงเวลาที่ชน และแนะนำเวลาว่างที่ใกล้ที่สุด
- ถ้าจัดเวลาอัตโนมัติไม่ครบ ระบบแสดงรายการที่จัดไม่ได้ พร้อมสาเหตุและคำแนะนำ (เพิ่มเวลา วัน หรือสนาม)

### จัดเวลาแข่ง (ผู้ดูแล) — อัตโนมัติตามกำหนดการและกฎ
- ระบบจัดเวลาให้อัตโนมัติตามวัน/ช่วงเวลาของแต่ละรอบ ไม่ให้ทีมเดียวกันแข่งชนเวลา สนามไม่ชน และรอบถัดไปหลังรอบก่อนจบ + พัก
- เมื่อลากทีมลงสาย หรือบันทึกผลแล้วรู้ทีมที่เข้ารอบ ระบบปรับเวลาให้อัตโนมัติ (ถ้าจำเป็นจะจัดใหม่ทั้งตาราง)
- ปุ่ม **จัดเวลาอัตโนมัติ** (หน้าตารางแข่ง / หน้าจัดเวลา) จัดใหม่ทุกนัด — ไม่เปลี่ยนทีมในสาย, ไม่เปลี่ยนวันที่ล็อกไว้ และนัดที่แข่งแล้ว
- วันแข่งจริงช้ากว่ากำหนด: หน้า **จัดเวลา** กด **⏱ เลื่อนเวลา** ที่หัวสนาม แล้วใส่จำนวนนาที — นัดที่ยังไม่แข่งของสนามนั้นเลื่อนตามกันทั้งหมด (ข้ามช่วงพักกลางวันให้เอง ถ้าทำให้ทีมชนเวลา ระบบถามก่อน)
- ปรับเวลาเองได้ที่หน้า **จัดเวลา** (ลากวาง) และกด **ล็อกตารางวันนี้** เมื่อยืนยันแล้ว
- เสร็จแล้วกด **เผยแพร่ขึ้นเว็บ**

### ผู้ชม
เปิดลิงก์ได้เลย — เห็นตารางและผลที่ผู้ดูแลเผยแพร่ล่าสุด หน้า “ตารางแข่ง” ดูได้ทั้งแบบรายการ และแบบ **ตามสนาม** (ตารางเวลาแยกคอลัมน์ตามสนามของแต่ละวัน) หน้าเว็บตรวจผลใหม่ทุก 1 นาทีและอัปเดตให้เอง (ดูได้อย่างเดียว) · หน้า “ตารางแข่ง” มี **รายงานประจำวัน** สรุปผลแต่ละวันแยกตามกีฬาและประเภท (พิมพ์ / Excel ได้)

### ผู้ดูแลการแข่งขัน (บันทึกผล)
1. เมนู ⋯ → **เข้าสู่ระบบผู้ดูแล** แล้วใส่ชื่อผู้ใช้และรหัสผ่าน
2. บันทึกผล / แก้วันเวลา ตามปกติ (ผลจะอยู่ในเครื่องนี้ก่อน)
3. กด **เผยแพร่ขึ้นเว็บ** ที่แถบด้านบน — ผู้ชมจะเห็นภายในประมาณ 1 นาที

ครั้งแรกที่กดเผยแพร่ ระบบจะขอ **GitHub token** (ทำครั้งเดียวต่อเครื่อง):
- เปิด https://github.com/settings/personal-access-tokens/new
- Repository access → *Only select repositories* → `nattakit2540-ops/nongphueng-sports`
- Repository permissions → **Contents: Read and write** → Generate token แล้ววางในหน้าเว็บ

token เก็บไว้ในเบราว์เซอร์เครื่องนั้นเท่านั้น ใช้บนเครื่องของผู้ดูแลเท่านั้น
ไม่อยากใช้ token: กด *ดาวน์โหลด data.json* ในหน้าต่างเดียวกัน แล้วอัปโหลดทับไฟล์ `data.json` ในหน้า GitHub ของ repo

> หมายเหตุ: การล็อกอินทำงานในเบราว์เซอร์ (เว็บแบบไฟล์เดียว ไม่มีเซิร์ฟเวอร์) จึงใช้กันการแก้ไขโดยไม่ตั้งใจได้ แต่ไม่ใช่ระบบความปลอดภัยเต็มรูปแบบ ข้อมูลที่ทุกคนเห็นจะเปลี่ยนได้เฉพาะผู้ที่มี GitHub token เท่านั้น
