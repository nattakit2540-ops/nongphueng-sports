# แข่งขันกีฬาอำเภอเกษตรวิสัย “หนองผึ้งเกมส์” 2026

เว็บไซต์จัดสาย ตารางแข่งขัน และบันทึกผลการแข่งขันกีฬาอำเภอเกษตรวิสัย “หนองผึ้งเกมส์” (ธีม ขาว · ชมพู · ฟ้า พร้อมแอนิเมชัน) — ไฟล์เดียว (`index.html`) ไม่ต้องติดตั้งอะไร

## ความสามารถ
- **หน้าแรก** — นับถอยหลังสู่วันแข่ง, ภาพรวม 6 ชนิดกีฬา, นัดถัดไป, ทำเนียบผู้ชนะเลิศ
- **ผังการแข่งขัน** — แพ้คัดออก 6 ทีม (สายบน / สายล่าง / ชิงชนะเลิศ) แตะคู่แข่งขันเพื่อบันทึกผล ผู้ชนะเข้ารอบอัตโนมัติ
- **ตารางแข่งขัน** — แยกตามวัน กรองตามกีฬา รุ่น และค้นหา, สุ่มจัดตารางอัตโนมัติ, ส่งออก Excel (CSV), พิมพ์ / PDF
- **ตั้งค่า** — วัน เวลา เวลาพัก สนาม และนาทีต่อนัดของแต่ละกีฬา พร้อมตรวจทีมและสนามชนกัน

ชนิดกีฬา: ฟุตบอล · ฟุตซอล · วอลเลย์บอล · ปิงปอง · เปตอง · ตะกร้อ
รุ่น: ประถมชาย · ประถมหญิง · มัธยมชาย · มัธยมหญิง (รวม 24 รุ่น 120 นัด)

## การใช้งาน
เปิด `index.html` ด้วย Chrome / Edge / Safari หรือเปิดผ่าน GitHub Pages

## ข้อควรรู้
ข้อมูล (ผลคะแนน วันเวลา) บันทึกใน **เบราว์เซอร์ของแต่ละเครื่อง** — ผู้ชมที่เปิดเว็บจะไม่เห็นผลที่อีกเครื่องบันทึกไว้
ใช้เมนู ⋯ → *สำรองข้อมูล (JSON)* / *นำเข้าข้อมูลสำรอง* เพื่อย้ายข้อมูลระหว่างเครื่อง และควรสำรองเป็นระยะ
