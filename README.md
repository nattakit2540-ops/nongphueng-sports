# แข่งขันกีฬาอำเภอเกษตรวิสัย “หนองผึ้งเกมส์” 2026

เว็บไซต์จัดสาย ตารางแข่งขัน และบันทึกผลการแข่งขันกีฬาอำเภอเกษตรวิสัย “หนองผึ้งเกมส์” (ธีม ขาว · ชมพู · ฟ้า พร้อมแอนิเมชัน) — ไฟล์เดียว (`index.html`) ไม่ต้องติดตั้งอะไร

## ความสามารถ
- **หน้าแรก** — นับถอยหลังสู่วันแข่ง, ภาพรวม 6 ชนิดกีฬา, นัดถัดไป, ทำเนียบผู้ชนะเลิศ
- **ผังการแข่งขัน** — แพ้คัดออก 6 ทีม (สายบน / สายล่าง / ชิงชนะเลิศ) ผู้ดูแล **ลากทีมจากกล่องทีมมาวางในสายเอง** ได้ทุกประเภท (เริ่มต้นเป็นช่องว่าง ไม่จับคู่ให้อัตโนมัติ) และแตะคู่แข่งขันเพื่อบันทึกผล ผู้ชนะเข้ารอบอัตโนมัติ
- **ตารางแข่งขัน** — แยกตามวัน กรองตามกีฬา รุ่น และค้นหา, สุ่มจัดตารางอัตโนมัติ, ส่งออก Excel (CSV), พิมพ์ / PDF
- **ตั้งค่า** (เฉพาะผู้ดูแล) — วัน เวลา เวลาพัก ชื่อสนาม จำนวนสนาม และนาทีต่อนัดของแต่ละกีฬา พร้อมตรวจทีมและสนามชนกัน

ประเภทการแข่งขัน (ทั้งระดับประถมและมัธยม) รวม 38 ประเภท 190 นัด
- ฟุตบอล · ฟุตซอล · วอลเลย์บอล · ตะกร้อ — ชาย / หญิง
- ปิงปอง — เดี่ยว ช/ญ · คู่ ช/ญ · ทีมผสม
- เปตอง — เดี่ยว ช/ญ · คู่ ช/ญ · ทีม ช/ญ

ทีมที่เข้าแข่ง: ศูนย์เครือข่ายที่ 8, 9, 10 (ชุดที่ 1 และ 2) — ผู้ดูแลจัดลงสายบน/สายล่างเองทุกประเภท

## การใช้งาน
เว็บไซต์: https://nattakit2540-ops.github.io/nongphueng-sports/

### ผู้ชม
เปิดลิงก์ได้เลย — เห็นตารางและผลที่ผู้ดูแลเผยแพร่ล่าสุด หน้าเว็บตรวจผลใหม่ทุก 1 นาทีและอัปเดตให้เอง (ดูได้อย่างเดียว)

### ผู้ดูแลการแข่งขัน (บันทึกผล)
1. เมนู ⋯ → **เข้าสู่ระบบผู้ดูแล** แล้วใส่ชื่อผู้ใช้และรหัสผ่าน
2. บันทึกผล / แก้วันเวลา ตามปกติ (ผลจะอยู่ในเครื่องนี้ก่อน)
3. กด **เผยแพร่ขึ้นเว็บ** ที่แถบด้านบน — ผู้ชมจะเห็นภายในประมาณ 1–2 นาที

ครั้งแรกที่กดเผยแพร่ ระบบจะขอ **GitHub token** (ทำครั้งเดียวต่อเครื่อง):
- เปิด https://github.com/settings/personal-access-tokens/new
- Repository access → *Only select repositories* → `nattakit2540-ops/nongphueng-sports`
- Repository permissions → **Contents: Read and write** → Generate token แล้ววางในหน้าเว็บ

token เก็บไว้ในเบราว์เซอร์เครื่องนั้นเท่านั้น ใช้บนเครื่องของผู้ดูแลเท่านั้น
ไม่อยากใช้ token: กด *ดาวน์โหลด data.json* ในหน้าต่างเดียวกัน แล้วอัปโหลดทับไฟล์ `data.json` ในหน้า GitHub ของ repo

> หมายเหตุ: การล็อกอินทำงานในเบราว์เซอร์ (เว็บแบบไฟล์เดียว ไม่มีเซิร์ฟเวอร์) จึงใช้กันการแก้ไขโดยไม่ตั้งใจได้ แต่ไม่ใช่ระบบความปลอดภัยเต็มรูปแบบ ข้อมูลที่ทุกคนเห็นจะเปลี่ยนได้เฉพาะผู้ที่มี GitHub token เท่านั้น

## ข้อมูล
- `data.json` — ข้อมูลที่เผยแพร่ (ตาราง ผลคะแนน การตั้งค่า) ที่ทุกคนเห็น
- เมนู ⋯ → *สำรองข้อมูล (JSON)* / *นำเข้าข้อมูลสำรอง* ใช้ย้ายข้อมูลระหว่างเครื่องของผู้ดูแล
